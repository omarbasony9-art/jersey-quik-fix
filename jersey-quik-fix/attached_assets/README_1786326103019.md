# Family & Friends Community Admin

Standalone admin dashboard for managing the Family & Friends Community section.

## What you can edit

- Homepage hero text
- Community name
- Announcements
- Events
- Big community actions
- Progress and participant counts
- Member count / homepage stats
- Footer message
- Contact email
- Signup enabled/disabled
- Public/private status

## Current storage

This version saves everything in browser `localStorage`.

That means:
- edits persist on the same browser/device
- no database is required
- other users/devices will not automatically see the same edits
- you can export/import a JSON backup

## Production upgrade

For a real site, connect this admin to:
- authenticated admin accounts
- database (Postgres/Supabase/etc.)
- API endpoints
- community frontend
- image uploads
- RSVP database
- email/SMS/push notifications
