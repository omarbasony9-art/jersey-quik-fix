# Jersey Quik Fix Admin Control Center

This is a standalone admin dashboard starter you can give to Replit.

It includes editable sections for:
- Website pages
- Homepage content
- Repairs
- Products
- Inventory
- Orders
- Customers
- Trade-ins
- Events
- Announcements
- Big Actions
- Community members
- Photos
- Employees
- Demo requests
- Settings

## Current storage
This starter uses localStorage so it works immediately.

## Tell Replit this after uploading
Use this admin dashboard as the base. Do not redesign it. Replace localStorage in admin-data.js with PostgreSQL-backed API routes, add admin authentication and role-based server-side permissions, then connect the public Jersey Quik Fix pages so changes made in Admin update the live site for all users.

## Production requirements
- PostgreSQL
- Protected /admin route
- Owner/admin roles
- Server-side authorization
- Audit logs
- Image uploads
- Validation
- Environment variables
