# Family & Friends Community

A standalone responsive community section for events, major announcements, and group actions.

## Included

- Featured announcements
- Upcoming events
- RSVP interactions
- Add-event demo form
- Big community action/progress cards
- Email update signup UI
- Event countdown
- Responsive mobile layout

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

Example:

```bash
npx serve .
```

## Render deployment

This can be deployed as a **Static Site** on Render.

- Build command: leave blank
- Publish directory: `.`

## Backend-ready

The current project uses frontend demo data only. For a production version, connect:
- authentication
- private member accounts
- database
- admin event/announcement management
- RSVP storage
- email/SMS notifications
- photo uploads
