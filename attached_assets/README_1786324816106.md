# GameVault - Render-ready gaming ecommerce demo

Original React/Express storefront inspired by modern game retailers.

## Features
- Responsive gaming retail homepage
- Search and category filtering
- Product cards and cart
- Trade-in value estimator
- Trading cards / collectibles / retro categories
- Member/rewards section
- Express server for Render deployment
- `render.yaml` included

## Local run
```bash
npm install
npm run dev
```

## Deploy to Render
1. Push this folder to GitHub.
2. In Render, create a new Web Service from that repo.
3. Build command: `npm install && npm run build`
4. Start command: `npm start`
5. Node version can use Render's default current LTS.

Or use the included `render.yaml` with Render Blueprint.

## Important
This demo uses mock products and demo trade values. Checkout, real inventory, authentication, payments, order history, store locator, database storage, and admin tools are not yet connected.

The site is not affiliated with GameStop and intentionally uses original branding/code.
