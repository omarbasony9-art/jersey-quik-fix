# RepairHub

A Render-ready React + Express repair-business website inspired by the overall UX patterns of major device-repair chains, with original branding, copy, components, and styling.

## Included
- Responsive repair-business homepage
- Device repair categories
- Interactive repair-request modal
- Issue selection flow
- Demo location selector / ZIP search UI
- Reviews and trust sections
- Popular repair services
- Tech guides
- FAQ accordion
- Mobile navigation
- Render deployment configuration

## Run locally
```bash
npm install
npm run dev
```

## Production test
```bash
npm run build
npm start
```

## Deploy to Render
Push this folder to GitHub and create a Render Web Service, or use `render.yaml`.

Build command:
```bash
npm install && npm run build
```

Start command:
```bash
npm start
```

## Important
This is a frontend/demo foundation. The repair flow currently uses demo data. For a production business, connect it to your real database/API for locations, appointments, pricing, customer accounts, repair tracking, inventory, payments, email/SMS confirmations, and an admin dashboard.
